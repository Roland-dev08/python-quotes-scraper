# Python Quotes Scraper

A simple Python web scraper built with requests and BeautifulSoup to extract quotes and authors from quotes.toscrape.com.

## Features
- Fetches top quotes from the target website
- Extracts author names along with quote text
- Displays structured output in the terminal

## Tech Stack
- Python 3
- requests
- beautifulsoup4

## How to Run
```bash
pip install requests beautifulsoup4
python scraper.py
```
